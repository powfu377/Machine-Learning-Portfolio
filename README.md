# Advanced Customer Segmentation using RFM Analysis & K-Means

An end-to-end Machine Learning project for segmenting e-commerce customers based on their purchasing behavior using **RFM (Recency, Frequency, Monetary)** analysis and **K-Means Clustering**.

---

## 📌 Project Overview
Customer Segmentation is essential for targeted marketing, improving customer retention, and maximizing Revenue. This project cleans real-world e-commerce transactional data, constructs customer-level RFM metrics, pre-processes feature distributions, and applies **K-Means Clustering** wrapped inside a `scikit-learn` Pipeline.

---

## 🛠️ Data Preprocessing & Cleaning Strategy
1. **Irrelevant Features Removal:** Columns like `StockCode`, `Description`, and `Country` were removed to focus solely on quantitative behavior metrics.
2. **Missing & Invalid Data Handling:**
   - Rows without `CustomerID` were removed.
   - Cancelled invoices (starting with `'C'`) were filtered out.
   - Non-positive values for `Quantity` and `UnitPrice` ($\le 0$) were dropped.
3. **RFM Feature Engineering:**
   - **Recency ($R$):** Days since the customer's last purchase relative to a fixed snapshot date.
   - **Frequency ($F$):** Number of unique invoices generated by the customer.
   - **Monetary ($M$):** Total dollar amount spent across all transactions.

---

## ⚙️ Model Architecture & Pipeline
To prevent data leakage and handle heavy right-skewness common in financial metrics:
1. **Log Transformation (`np.log1p`):** Normalizes the distributions of Recency, Frequency, and Monetary metrics.
2. **Standard Scaling (`StandardScaler`):** Normalizes feature scale to maintain distance equality in K-Means distance calculations.
3. **K-Means Clustering ($K=4$):** Evaluated using the **Elbow Method** and **Silhouette Score**. Although $K=2$ yields a higher mathematical score, $K=4$ was selected for actionable business intelligence and campaign specificity.

```python
final_pipeline = Pipeline([
    ('log_transform', FunctionTransformer(np.log1p, validate=False)),
    ('scaler', StandardScaler()),
    ('kmeans', KMeans(n_clusters=4, random_state=42, n_init=10))
])
```
